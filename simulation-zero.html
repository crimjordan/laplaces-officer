What this actually simulates

Each of 144 synthetic districts has a fixed baseline incident intensity. Each week, resources are allocated using the selected policy. Detection visibility affects how many incidents become recorded, while a hypothetical deterrence parameter reduces underlying incidents in patrolled cells. Recorded incidents then feed the next predictive allocation. The model uses a reproducible pseudo-random generator, not live data. It deliberately omits population dynamics, spatial spillovers, legal constraints, and many mechanisms of real-world policing.

The “underlying need” policy is an omniscient benchmark unavailable to real police. The two-policy comparison is an educational counterfactual, not causal evidence. A real deployment would require much more than this model—and this tool is not intended to support policing decisions.
